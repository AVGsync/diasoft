# Реализованная функциональность

- Загрузка дипломов в формате JSON/CSV;
- Криптографическая обработка и подписывание дипломов;
- Публичная верификация дипломов по QR-коду или JWT;

**Особенность проекта в следующем:**

- Асинхронная обработка через Kafka для высокой производительности;
- Интеграция с вузами через API-ключи;
- Публичный портал для проверки подлинности дипломов;

# Основной стек технологий

- Go, Rust;
- HTML, CSS, JavaScript, TypeScript;
- PostgreSQL, Redis;
- Docker, Docker Compose;
- React, Vue.js;
- Git;

# УСТАНОВКА

## Установка пакетов

Выполните:

```bash
sudo apt-get update
sudo apt-get upgrade
sudo apt-get install docker.io docker-compose git
git clone https://github.com/your-repo/diasoft
cd diasoft
```

## База данных

База данных PostgreSQL разворачивается автоматически через Docker Compose. Подключение к базе прописано в конфигурационных файлах сервисов.

## Выполнение миграций

Миграции применяются автоматически при запуске контейнера `db-migrate`.

## Установка зависимостей проекта

Установка зависимостей осуществляется через Docker. Зависимости для Go и Rust проектов устанавливаются автоматически в контейнерах.
