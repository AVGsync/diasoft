Для работодателей (B2B)
1. PDF-сертификат верификации GET /api/v1/verify/{hash}/certificate — генерирует PDF с результатом: ФИО, университет, номер диплома, статус, timestamp, хеш, QR-код. Работодатель скачивает и прикладывает к делу кандидата. Без этого ему приходится скриншотить JSON.

4. Аналитический дашборд GET /api/v1/stats — количество проверок за период, топ университетов, распределение статусов, география запросов по IP. Помогает университетам понимать, кто и как часто проверяет их дипломы.

5. API-ключи для интеграции Выдача API-ключей университетам/работодателям с квотами и отдельной аналитикой. Сейчас API полностью публичный — нет возможности отличить запросы банка от запросов случайного пользователя.

Для выпускников (B2C)
6. Публичная страница верификации GET /verify/{hash} — HTML-страница (не JSON), которую работодатель открывает по ссылке из QR-кода на бумажном дипломе. Показывает: статус, ФИО, университет, год. Не требует Postman — работает в любом браузере.

Инфраструктура / Безопасность
8. OpenAPI + Swagger UI GET /docs — интерактивная документация. Любой интегратор (HR-система, банк) может протестировать API прямо в браузере без Postman. Стандарт для публичных API.

9. Audit log проверок Таблица verification_logs с каждой проверкой: IP, user-agent, хеш, результат, timestamp. Полезно для расследования инцидентов и аналитики. Сейчас проверки логируются только в stdout и теряются при рестарте.
